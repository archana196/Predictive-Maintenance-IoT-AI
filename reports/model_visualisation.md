# Model Visualization Report

## Feature Importance
Shows top features contributing to failure prediction.
Rolling mean and std of Torque and Tool wear are most important.

## Confusion Matrix
Shows correct vs incorrect predictions.
True Positives = correctly predicted failures.

## ROC Curve
AUC score shows model discrimination ability.
Higher AUC = better model.

## Precision-Recall Curve
Better metric for imbalanced datasets.
Shows tradeoff between precision and recall.
