# Ablation Study Framework

## Model A
Internal telemetry features only
(Air temperature, Process temperature, Rotational speed, Torque, Tool wear, Rolling features)

## Model B
Internal telemetry + contextual features
(Model A features + Temperature difference, Load ratio, Shift encoding, Interaction features)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## Purpose
Compare whether adding contextual features improves machine failure prediction performance.
